# 202507108-VIDEOJUEGO
se explica como funciona el juego y todas las fases que lleva al realizarlo
#Fase 1: Análisis

En esta fase se definieron los requisitos funcionales y no funcionales del videojuego Legado de los Guardianes. Se establecieron características como el sistema de misiones, combate, niveles, inventario, guardado de partida y calidad visual, además de determinar los objetivos y mecánicas principales del juego.

#Fase 2: Diagrama

Se diseñó un diagrama de flujo que representa el funcionamiento del juego desde el menú principal hasta la victoria final. El diagrama incluye la exploración de escenarios, realización de misiones, combate contra enemigos y jefes, obtención de recompensas, uso del inventario y progresión por niveles.

#Fase 3: Código

Se desarrolló el programa en Python implementando las funcionalidades definidas en el análisis y representadas en el diagrama. El código incluye menú principal, sistema de misiones, combate con diferentes armas, experiencia, niveles, inventario, recompensas, guardado de partida y condiciones de victoria o derrota.

#Fase 4: Presentación en GitHub

Finalmente, el proyecto se organizó y publicó en GitHub para presentar el código fuente, la documentación y el diagrama de flujo. Esto permite almacenar el proyecto de forma profesional, facilitar su acceso y demostrar el desarrollo completo del videojuego Legado de los Guardianes.
